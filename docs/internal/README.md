# Internal notes

Working artifacts, kept for their history: one design spec per feature
(`specs/`), one implementation plan per round of work (`plans/`), the probes
that settled a design question (`probes/`), and the phase-by-phase trace of how
the repository got here (`build-history.md`).

They record *why* things were built the way they were, as understood at the
time. They are not documentation and not an authority: paths and decisions
inside them may be out of date, and they cite tracker issues freely. The
documentation is the [README](../../README.md), the
[CHANGELOG](../../CHANGELOG.md) and the pages in [`docs/`](..); code comments
cite those, never these notes.
